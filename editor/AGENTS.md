# Конфигурация анализатора

Эта папка содержит локальную базу `compile_commands.json` для clangd.
Она описывает исходник проекта и копию `mod.wh.cpp` в EditorWorkspace Windhawk;
не является отдельной системой сборки и не изменяет код мода.
Машинные пути исключены из Git правилом корневого `.gitignore`.

Флаги должны соответствовать `compile_flags.txt` установленного редактора
и `@compilerOptions` нового мода, включая include-путь именно этого проекта.
Не брать пути и исходники из базы исходного мода. Скрипт генерации не требуется.

Корневая `.clangd` использует эту папку. Общая `.clangd` в EditorWorkspace
также должна указывать сюда при редактировании Sub2API-мода. При переходе
к другому моду переключать её на базу соответствующего проекта: автоматического
выбора по `@id` нет. Затем пользователь выполняет в палитре команд редактора
`clangd: Restart language server`.

Изменение конфигурации не разрешает запуск clangd, компилятора, скриптов,
тестов или Windhawk. Без отдельного разрешения проверять только содержимое
JSON, существование путей и соответствие флагов; исчезновение диагностики
и успешность сборки подтверждаются отдельно.
