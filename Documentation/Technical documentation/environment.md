## Границы первоначального обследования

- Версия и возможности реально развёрнутого sub2api, доступ конкретного ключа
  и фактические upstream payload. Локальный код не подтверждает установку сервера.
- Набор мониторов, масштабирование DPI и поведение двух виджетов одновременно:
  это проверяется на работающем интерфейсе, а не по исходникам.
- Открытие ссылки значка мода в Windhawk. Пользователь предоставил адрес
  https://github.com/RuffID/windhawk-sub2api-taskbar-dashboard, он подключён;
  переход после этой правки ещё не проверен.
- Отдельные разрешения на точные команды компиляции/harness и включение мода
  в Windhawk перед соответствующей проверкой.

На момент обследования эти сведения не позволяли заранее отметить внешнюю
приёмку завершённой. Итоговая приёмка и принятые ограничения приведены ниже. Никакая установленная программа
и конфигурация Codex Desktop в рамках обследования не изменялись.

## Исправление конфигурации редактора 05.11.2026

Общая `.clangd` в `D:/Programs/Windhawk/AppData/EditorWorkspace` ссылалась
на базу исходного Codex LB-мода. Её include-путь выбирал чужие заголовки
с namespace `codex_dashboard` при анализе нового исходника, использующего
`sub2api_dashboard`.

Добавлены корневая `.clangd` и отдельная локальная `editor/compile_commands.json`
нового проекта. База описывает `mod.wh.cpp` проекта и его копию в EditorWorkspace;
параметры взяты из локального `compile_flags.txt` и `@compilerOptions` нового мода.
Общая `.clangd` переключена на эту базу. Машинный JSON исключён из Git.
Конфигурация общая для редактора: при смене мода требуется переключить базу.

Проверка ограничена чтением конфигурации, JSON, флагов и существования путей.
Перезапуск анализатора остаётся пользователю: `Ctrl+Shift+P` →
`clangd: Restart language server`. Компилятор, скрипты, тесты и Windhawk
не запускались; исчезновение диагностики и успешность сборки не подтверждены.
Статусы этапов 03/04 и границы визуальной приёмки не изменены.
