## Цель и результат

Собственные метаданные, entrypoints и жизненный цикл мода с минимально
необходимыми зависимостями исходной UI-основы.

## Зависимости и границы

Реализация поручена и выполнена в пределах этапа 02. До интеграции данные могут
оставаться недоступными; не подключать по умолчанию сервер codex-lb.
Не копировать весь соседний каталог вместе со служебными файлами.

## Проверки и критерии готовности

- [x] Статически прослежены init/failure/unload без оставленных задач и callbacks.
- [x] Существующие пользовательские настройки и файлы другого мода не затрагиваются.
- [x] Нет импортированных секретов, серверного адреса и машинных compile databases.
- [x] Include-путь относится к новой папке, описание не обещает готовую интеграцию.

Сборку через stdin с фактическими параметрами подтвердить в 05.01 при разрешении;
недоступность этой проверки не маскировать статусом «проверено».

## Фактический результат

Созданы mod.wh.cpp и 17 заголовков src из одной единицы трансляции.
Переиспользованы XAML/taskbar, popup/GDI/DPI, watcher, таймеры и cleanup эталона.
Нет accounts/session/usage и старой авторизации. Из renderer исключена отдельная
диагностика переавторизации. Собственные ID, namespace, COM CLSID, XAML-имена,
класс окна, сообщения, log/cache/mutex; ссылки нового мода на старый репозиторий нет.
Отдельный cache перенесён как основа этапа 04, сейчас не читается и не записывается.

Статически прослежены init/failure/after-init/settings/unload: остановка обновлений,
отмена, завершение timer/manual work, отписка watcher/событий, удаление только
своих виджетов, popup и hook, снятие регистрации окна, закрытие событий/модулей.
Для совместного размещения учитывается ширина исходного виджета и отслеживается
её изменение. Runtime приёмка обоих модов остаётся в 05.02.
Локальные AGENTS.md созданы для всех папок кода; документация актуализирована.
Сборка, тестовые программы и UI не запускались.
