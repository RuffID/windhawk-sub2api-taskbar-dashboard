# 04.01. Привязка данных к прежнему интерфейсу

Статус: verification — реализация готова, runtime и визуальная приёмка открыты

[Этап](main.md) · [План](../main.md)

## Цель и результат

Taskbar и popup показывают OpenAI-данные sub2api, сохраняя геометрию, цвета,
шрифты, прозрачность, прокрутку и взаимодействия исходного мода.

## Зависимости и границы

02.01, 03.02–03.03. Использовать существующие визуальные компоненты; не добавлять
новую навигацию или действия сброса/изменения аккаунтов.

## Затрагиваемые части и работы

- [x] Подключить единый snapshot к проценту taskbar и заголовку popup; показать
  согласованные состояния недоступности, неполноты и устаревания.
- [x] Сохранить геометрию, добавляя только согласованные `*`, счётчик полноты
  и статусы качества данных. Числовой возраст скрыт по последующей просьбе
  пользователя. После 15 минут устаревший процент не остаётся текущим средним.
- [x] Сопоставить карточки, сортировку, окна, общие статусы, Reset и сроки;
  адаптировать названия сервиса и подписи без изменения оформления.
- [x] Не переносить из эталона значок и сообщение необходимости переавторизации;
  не создавать для них поле модели или ожидание нового серверного контракта.
  Сохранить показ известных общих статусов и ошибок.
- [ ] Сохранить кнопки, области клика, закрытие вне окна, время обновления,
  масштабирование DPI, несколько панелей задач и восстановление XAML-виджета.
- [x] Актуализировать локальные инструкции UI, README и описание `mod.wh.cpp`.

## Проверки и критерии готовности

- [ ] Макет с 1/4/многими карточками, отсутствующим 5h, месячным окном,
  длинным email, общей ошибкой аккаунта и неизвестным Reset не теряет текст/кнопки.
- [ ] Пороговые цвета и badge соответствуют требованиям; текст сохраняет
  непрозрачность, цвет рамки версии не меняет цвет текста.
- [ ] Статическая логика hit-test и scroll не нарушает доступность элементов.

Сравнительные скриншоты и реальные DPI/мониторы проверяются отдельно в 05.02.
До этого этап нельзя считать визуально принятым.

## Фактический результат

Реализация подключена к существующему snapshot без нового loader или формулы.
Сохранены окно 720×340, две карточки в строке, шаг 124, шрифты, цвета/alpha,
scroll/DPI и взаимодействия. Внутри заголовка расширена область счётчика;
качество вынесено ниже reset; числовой возраст скрыт. Доступные weekly/monthly не смешиваются
со средним; сортировка по дробному остатку, неизвестные после известных.
Reset с неизвестным count/нулём скрыт, неизвестный expiry не скрывает count.
Граница семи дней красная. Отдельной диагностики переавторизации нет.
По уточнению пользователя отсчёт Reset от суток показывает также часы (`1d 19h`);
ширина badge учитывает срок. Fixtures обновлены без запуска, компиляция и
визуальная проверка правки не выполнялись; статус этапа не меняется.

Статически проверены данные, координаты строк, hit-test, scroll и сохранность
пути refresh/outside-click/recovery. Добавлены fixtures проекции/Reset/колонок
и состояний версий; они не запускались. Кнопки, DPI и восстановление требуют
runtime-проверки, поэтому соответствующий пункт работ оставлен открытым.
Скриншотов и визуальной приёмки нет; это не подтверждение совпадения на экране.
