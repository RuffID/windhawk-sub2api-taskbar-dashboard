## Цель и результат

Версия установленного sub2api, независимая проверка опубликованных релизов
и правильные ссылки в существующем оформлении.

## Зависимости и границы

02.02 и подтверждённый контракт `system.read`. Источник — официальный
`Wei-Shaw/sub2api`, включая опубликованные prerelease. Адрес публичного
репозитория нового мода нужен до поставки
для второй GitHub-ссылки (Т3); не создавать репозиторий или релиз автоматически.

## Проверки и критерии готовности

- [ ] Fixtures покрывают равную/старую/новую версию, beta.9/beta.10, stable,
  неизвестную текущую версию, не-JSON, 403/429 и отсутствие срока повтора.
- [ ] Повторное открытие кеша и два клиента соблюдают единый часовой минимум,
  не обращаясь к кешу исходного мода; отмена не оставляет вечную резервацию.
- [ ] Ошибка GitHub не скрывает аккаунты и не сообщает «Нет новых версий».
- [ ] Исходный tag экранируется в URL; области клика соответствуют своему назначению.

Фактическая проверка сервера/GitHub и пользовательского кеша разрешается отдельно;
изолированные тесты используют временный кеш и фиктивные ответы.

## Фактический результат

Два административных GET читаются по фактическому контракту; непустой warning
не выдаётся за успех. Taskbar использует только серверный has_update.
Независимая GitHub-проверка включает prerelease, сохраняет исходный tag и
экранирует его как URL-сегмент. Полный/ограниченный ключи не различаются префиксом.
Pending/Unknown/Failed/RateLimited/актуальность/обновление видимы раздельно.

Persistent cache и mutex имеют отдельные имена Sub2ApiTaskbarDashboard.
Резервация сохраняется до запроса и завершается при отмене/исключении с
сохранением часовой паузы; более поздние Retry-After/Reset продлевают её.
Отдельный PTP_WORK ограничен по времени, drain происходит до reset/settings;
публикация проверяет generation/cancel. Критерий успеха аккаунтов не менялся.
Добавлен tests/popup_versions.cpp с production fixtures, временным кешем,
двумя клиентами, ошибками/отменой и ссылками. Сборка и запуск не выполнялись,
поэтому критерии проверок выше остаются открытыми. Реальных запросов не было.
