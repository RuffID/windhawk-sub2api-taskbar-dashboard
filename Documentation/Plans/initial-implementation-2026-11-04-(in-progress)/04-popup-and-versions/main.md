# Этап 04. Popup и версии

Статус: not-started

## Цель и границы

Отобразить snapshot sub2api в прежнем оформлении и адаптировать проверку версий.
[Общий план](../main.md).

Затрагиваются `src/ui`, `src/versions`, refresh/state, README и описание
мода. 04.01 зависит от 03.02–03.03; 04.02 можно вести отдельно после 02.02.
Источник релизов — официальный `Wei-Shaw/sub2api`, включая prerelease.
Обновление сервера, расход Reset и управление аккаунтами не добавляются.
Отдельный значок и сообщение переавторизации исключены из эталонного поведения;
остальное оформление и общие статусы/ошибки сохраняются.

## Проверки и приёмка

- [ ] Внешний вид соответствует бизнес-требованиям и эталону, включая empty/error states.
- [ ] Taskbar и заголовок popup показывают одно недельное среднее.
- [ ] Ошибка версий отделена от ошибки аккаунтов, неизвестная версия не считается актуальной.
- [ ] GitHub имеет отдельный кеш/mutex, часовой минимум и обработку rate limit.
- [ ] Ссылки sub2api и нового мода ведут к выбранным владельцам.

Связанные [вопросы](../open-questions.md): Т3 — внешняя приёмка и адрес репозитория мода.
Изолированные проверки
отрисовки не заменяют визуальную приёмку Windows в 05.02.

перенесена в этапе 02; аккаунты и версии ещё не загружаются. Это не выполнение
