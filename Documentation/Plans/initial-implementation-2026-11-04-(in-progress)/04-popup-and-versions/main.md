# Этап 04. Popup и версии

Статус: verification — 04.01/04.02 реализованы, сборка и проверки запуском открыты

## Цель и границы

Отобразить snapshot sub2api в прежнем оформлении и адаптировать проверку версий.
[Общий план](../main.md).

Затрагиваются `src/ui`, `src/versions`, refresh/state, README и описание
мода. 04.01 зависит от 03.02–03.03; 04.02 можно вести отдельно после 02.02.
Источник релизов — официальный `Wei-Shaw/sub2api`, включая prerelease.
Обновление сервера, расход Reset и управление аккаунтами не добавляются.
Отдельный значок и сообщение переавторизации исключены из эталонного поведения;
остальное оформление и общие статусы/ошибки сохраняются.

## Проверки и приёмка

- [ ] Внешний вид соответствует бизнес-требованиям и эталону, включая empty/error states.
- [ ] Taskbar и заголовок popup показывают одно недельное среднее.
- [ ] Ошибка версий отделена от ошибки аккаунтов, неизвестная версия не считается актуальной.
- [ ] GitHub имеет отдельный кеш/mutex, часовой минимум и обработку rate limit.
- [ ] Ссылки sub2api и нового мода ведут к выбранным владельцам.

Связанные [вопросы](../open-questions.md): Т3 — внешняя приёмка.
Изолированные проверки
отрисовки не заменяют визуальную приёмку Windows в 05.02.

## Результат выполнения

04.01 и 04.02 реализованы поверх основы 03.01–03.03. Привязаны окна/сроки,
имя/email, Reset и отдельная строка качества без числового возраста, заголовок со счётчиком/*.
Подключены server version/has_update и независимые GitHub releases, SemVer,
отдельный persistent cache/mutex с часовым минимумом и rate limits. Версии
не ждут аккаунты и не задерживают их публикацию; account deadline/age timer
и критерий времени успеха сохранены. Добавлены fixtures production-кода.
[Устройство и ограничения](../../../Technical%20documentation/popup-and-versions.md).

Выполнен только статический разбор: 28 C++ файлов, 26 достижимых production,
локальные includes без разрывов/циклов, баланс скобок после исключения строк;
68 текстовых файлов без повреждений UTF-8 и 135 локальных ссылок с существующими
целями в 40 Markdown-файлах. Сборка, fixtures, сеть, сравнение скриншотов,
DPI и lifecycle в Windhawk не проверены; обязательные пункты приёмки выше
оставлены открытыми. Значок мода отключён до получения URL; ссылки сервера
ведут в Wei-Shaw/sub2api. Этап 03 остаётся in-progress, его проверки не закрыты.
Документы завершённых этапов 01/02, исходный мод, sub2api и .git не изменялись.
После реализации 04 работа остановлена, к 05 не переходили.
