## Цель и результат

Сводный недельный процент с однозначным признаком доступности, полноты и возраста.

## Зависимости и границы

данные из денежного `/v1/usage` и не смешивает месячные окна с недельными.

## Фактический результат

04.11.2026 добавлен production weekly calculation: полная account/user-пара,
freshest usable/меньший local ID, дробное среднее с итоговым half-up. Disabled/error
исключаются, достоверный 0% остаётся. Успешный ответ с пропавшей identity не
дополняется из кеша. Ошибки/deadline сохраняют старые квоты только до 900 секунд
по исходному fetched_at, затем процент недоступен. Один snapshot используется
taskbar/popup; generation/cancel gate блокирует старые настройки. Age timer без
HTTP обновляет пригодность раз в секунду. Полный критерий времени успеха описан
в технической документации; частичный результат и старение его не обновляют.
Статически разобраны перечисленные ветки; добавлены fixtures дробей, дублей,
899/900/901, ошибок и publication gate. Сборка/fixtures/lifecycle в Windhawk
не выполнялись, критерии приёмки выше остаются открытыми. Этап 04 не начат.
