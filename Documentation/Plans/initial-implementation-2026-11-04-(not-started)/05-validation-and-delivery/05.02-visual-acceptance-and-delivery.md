# 05.02. Реальная интеграция, внешний вид и передача

Статус: not-started

[Этап](main.md) · [План](../main.md)

## Цель и результат

Подтверждённая работа на целевой системе и короткая воспроизводимая инструкция
установки/обновления самостоятельного мода.

## Зависимости и границы

05.01, сервер/администраторский ключ, DPI/мониторы и адрес репозитория нового мода
из Т3. Локальные версии Windhawk и build Windows уже прочитаны без запуска;
их совместимость ещё проверяется. Требуется прямое разрешение на внешние
проверки и включение модификации.
Не перезапускать Explorer, менять сервер, вызывать отдельные операции сброса
или публиковать проект без отдельного поручения. Срабатывание уже настроенного
серверного автосброса после чтения квоты полным ключом допустимо.

## Затрагиваемые части и работы

- [ ] С разрешением подтвердить реальные ответы для используемого ключа и сопоставить
  среднее с серверными значениями выбранного пула, не раскрывая секреты в отчёте.
- [ ] Проверить сохранение оформления на целевых DPI и мониторах: процент,
  popup с 1/4/многими аккаунтами, карточки, Reset, сроки, версии и клики.
- [ ] Проверить manual refresh, ошибки доступа/сети, закрытие popup,
  смену настроек, reload/unload и восстановление панели задач.
- [ ] Проверить совместное включение с codex-lb-модом: отдельные виджеты,
  настройки, кеши, mutex и отсутствие удаления чужого элемента.
- [ ] Зафиксировать сравнительные изображения без email/адресов и других
  чувствительных данных, фактические версии среды и результат ручной приёмки.
- [ ] Обновить README: вся папка проекта, include-путь, выбранный доступ,
  компиляция/включение, обновление заголовков и точные ограничения.
- [ ] Актуализировать техническую документацию, статусы и оставшиеся вопросы;
  не добавлять несуществующую GitHub-ссылку или неподтверждённую лицензию.

## Проверки и критерии готовности

- [ ] Среднее и карточки подтверждены реальными разрешёнными данными.
- [ ] Ответы обрабатываются с учётом режима используемого ключа; серверный сигнал
  проверки автосброса при полном доступе допустим. Клиент не меняет настройки
  автоматики и не вызывает отдельные операции сброса.
- [ ] Отдельный значок/сообщение переавторизации отсутствуют согласно согласованному объёму.
- [ ] Пользователь подтвердил соответствие внешнего вида эталону.
- [ ] Общие ошибки/статусы, сроки и отсутствие данных имеют понятный результат.
- [ ] Второй мод продолжает работать; отмена/unload не оставляет виджет и запросы.
- [ ] Установка воспроизводима по README; комплект не содержит секретов/артефактов.

Непроведённая внешняя или визуальная проверка остаётся открытой; наличие
готовой сборки само по себе не закрывает этот подэтап.
