# Открытые вопросы

## Вопросы клиенту

Открытых вопросов по бизнес-правилам нет. Состав среднего, исключения, дубли,
неполнота, предел 15 минут, округление и официальный источник релизов внесены
в [требования](../../Business%20logic/requirements.md). Ответы здесь не архивируются.

### Т3. Недостающие сведения для внешней приёмки и публикации

Чтением файлов подтверждены Windhawk 1.7.3, наличие компилятора и x64 DLL;
из системных свойств прочитан Windows build 26200.9457/25H2/AMD64.
Пути и границы подтверждения описаны в
[документе среды](../../Technical%20documentation/environment.md).

По исходникам нельзя подтвердить версию развёрнутого sub2api, права конкретного
выданного ключа, реальные upstream payload, DPI/набор мониторов и рабочее
сосуществование модов. Эти сведения собираются в разрешённой внешней проверке.
Публичный адрес нового репозитория также пока не задан: Git не инициализирован,
репозиторий не публиковался. Для значка мода нельзя подставлять выдуманный URL.

Зависимые работы: [05.01](05-validation-and-delivery/05.01-isolated-validation.md)
для точной команды/toolchain, [05.02](05-validation-and-delivery/05.02-visual-acceptance-and-delivery.md)
для реального доступа/визуальной приёмки, [04.02](04-popup-and-versions/04.02-versions-and-cache.md)
для ссылки репозитория мода. Локальная реализация в основном не блокируется.
