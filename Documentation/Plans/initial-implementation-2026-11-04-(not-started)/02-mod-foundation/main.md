# Этап 02. Независимая основа мода

Статус: not-started

## Цель и границы

Перенести необходимую основу Windhawk, отделив новый мод от codex-lb и не меняя
его оформление. [Общий план](../main.md).

Документальные зависимости 01.01–01.02 выполнены; 02.01 начинается только
после поручения на реализацию;
02.02 зависит от 01.01. Сборка и включение не разрешаются самим переносом.
Затрагиваются будущие `mod.wh.cpp`, `src/core`, `src/config`, `src/network`,
`src/integration` и необходимые UI-зависимости в новом проекте.

## Проверки и приёмка

- [ ] Исходный проект и настройки установленного Windhawk не изменены.
- [ ] Нет чужих путей, реального адреса по умолчанию, секретов, кешей или `.git`.
- [ ] Весь код доступен из одной единицы трансляции, includes не образуют циклы.
- [ ] Настройки, отмена и освобождение ресурсов имеют определённого владельца.
- [ ] Одновременная работа двух модов не должна делить состояния, кеши и mutex.

Среда описана в [технической документации](../../../Technical%20documentation/environment.md).
Оставшиеся [внешние сведения](../open-questions.md) нужны для приёмки. Проверки toolchain выполняются
позднее при отдельном разрешении; здесь не заявляется успешная сборка.
