# 02.01. Перенос независимой основы Windhawk

Статус: not-started

[Этап](main.md) · [План](../main.md)

## Цель и результат

Собственные метаданные, entrypoints и жизненный цикл мода с минимально
необходимыми зависимостями исходной UI-основы.

## Зависимости и границы

Требуется последующее поручение на реализацию. До интеграции данные могут
оставаться недоступными; не подключать по умолчанию сервер codex-lb.
Не копировать весь соседний каталог вместе со служебными файлами.

## Затрагиваемые части и работы

- [ ] Добавить `mod.wh.cpp` и согласованный набор заголовков `src/`; сохранить
  одну единицу трансляции, относительные внутренние includes и явные зависимости.
- [ ] Задать отдельные ID, namespace, имена окон/сообщений и ресурсов; проверить
  места внедрения виджета, чтобы второй мод не заменял первый.
- [ ] Сохранить жизненный цикл taskbar/popup, ownership watcher и cleanup
  при unload, частичной ошибке и смене настроек.
- [ ] Создать локальные `AGENTS.md` только для реально созданных папок с кодом;
  обновить корневой README и техническую структуру.

## Проверки и критерии готовности

- [ ] Статически прослежены init/failure/unload без оставленных задач и callbacks.
- [ ] Существующие пользовательские настройки и файлы другого мода не затрагиваются.
- [ ] Нет импортированных секретов, серверного адреса и машинных compile databases.
- [ ] Include-путь относится к новой папке, описание не обещает готовую интеграцию.

Сборку через stdin с фактическими параметрами подтвердить в 05.01 при разрешении;
недоступность этой проверки не маскировать статусом «проверено».

## Фактический результат

Реализация не начата. Исходников и проверки жизненного цикла нового мода нет.
