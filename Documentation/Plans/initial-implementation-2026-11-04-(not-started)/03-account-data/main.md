# Этап 03. Аккаунты и недельное среднее

Статус: not-started

## Цель и границы

Получать выбранный OpenAI-пул и выдавать нормализованный snapshot карточек
и среднего недельного остатка. [Общий план](../main.md).

Зависимости: 01.01, 01.02, 02.01–02.02. Затрагиваются будущие `src/accounts`,
модель `src/core/state.h`, точки обновления; UI-оформление сюда не входит.

## Проверки и приёмка

- [ ] Список загружен со всех страниц, параллелизм GET quota ограничен, одна подписка учитывается один раз.
- [ ] Использованный и оставшийся процент не перепутаны; тип окна установлен по контракту.
- [ ] Ошибки отдельных GET quota не превращаются в полный успешный snapshot.
- [ ] Известные, отсутствующие и устаревшие значения обрабатываются согласно 01.02.
- [ ] Нормализованная модель позволяет сохранить внешний вид без чтения JSON из renderer.

Правила состава/расчёта описаны в 01.02 и актуальных бизнес-требованиях.
Отдельная диагностика переавторизации исключена из функциональности;
общие статусы и ошибки остаются. Данные берутся по выбранному прямому GET quota.
