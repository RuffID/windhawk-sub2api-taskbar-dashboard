## Зависимости и границы

01.02 и 02.02. Область определяется доступом ключа и утверждёнными фильтрами,
а не полным перечнем сервера. Не получать credentials ради отображения.

## Затрагиваемые части и работы

- [ ] Реализовать чтение всех страниц списка с фильтром OpenAI без ограничения
  одной группой/status; сохранить отключённые и ошибочные записи для карточек.
  Прямую quota загружать только для поддерживаемых OAuth-записей.
- [ ] Прочитать все страницы, обрабатывать пустую и изменяющуюся выборку,
  устранять повтор одного ID без скрытого повторного учёта.
- [ ] Выполнить ограниченное число параллельных GET quota; связать результаты
  по локальному ID, а не порядку завершения; отказ одной записи сохранять
  отдельно, не отменяя достоверные значения других. Общий usage batch не использовать
  как доказательство свежести лимитов.
- [ ] Ограничить параллелизм, обеспечить ownership/отмену всех запросов и безопасную
  диагностику ошибок без email, ключей и исходных тел ответов.
- [ ] Обновить `src/accounts/AGENTS.md` и описание потока данных.

## Проверки и критерии готовности

- [ ] В сценарии с числом аккаунтов больше размера страницы получены все записи.
- [ ] Другие платформы и недоступные группы не добавляются обходным запросом.
- [ ] Отказ страницы/quota сохраняет признак неполноты и не объявляет обновление успешным.
- [ ] Отмена и ошибка одной операции не оставляют фоновые запросы без владельца.
