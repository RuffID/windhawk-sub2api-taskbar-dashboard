# 03.03. Средний остаток недельного лимита

Статус: not-started

[Этап](main.md) · [План](../main.md)

## Цель и результат

Сводный недельный процент с однозначным признаком доступности, полноты и возраста.

## Зависимости и границы

03.02 и согласованные правила состава/давности/округления из 01.02. Расчёт не получает
данные из денежного `/v1/usage` и не смешивает месячные окна с недельными.

## Затрагиваемые части и работы

- [ ] Выделить расчёт по нормализованным snapshot с выбранным правилом включения
  аккаунтов и общей подписки; считать среднее по исходным дробным значениям.
- [ ] Группировать совпадающую полную пару account/user, выбирать свежий пригодный
  снимок, при равенстве — меньший локальный ID; не прибавлять Spark как вторую подписку.
- [ ] Исключать отключённые и неработающие записи, сохраняя карточки; не исключать
  исправный аккаунт только из-за достоверно исчерпанного недельного лимита 0%.
- [ ] Применить согласованные округление и диапазон значения, пустой пул,
  неполную выборку и старые данные после ошибки.
- [ ] Оставлять среднее известных данных с `*` и счётчиком полноты; после ошибки
  сохранять прежние значения с возрастом до 900 секунд по исходному `fetched_at`,
  затем исключать. Если пригодных значений нет, показывать недоступность.
- [ ] Округлять только итог до ближайшего целого, половины вверх, цвет по показанному числу.
- [ ] Передать taskbar и popup один результат обновления; фиксировать время
  успешного обновления только по определённому критерию, не при отказе.
- [ ] Обновить техническое описание и критерии fixtures без дублирования формулы
  в отдельном UI-расчёте.

## Проверки и критерии готовности

- [ ] Расход 20% и 60% даёт остатки 80% и 40%, среднее 60%.
- [ ] Проверены один аккаунт, дроби возле порогов 31/61, нулевой/полный остаток,
  отсутствие недельного окна и нулевое число пригодных значений.
- [ ] Пример с дублем подписки и частичной ошибкой соответствует решению 01.02.
- [ ] Проверены границы 899/900/901 секунд, повторный ответ со старым timestamp,
  пропавшая идентичность, disabled/error и 0% без исключения исчерпанного лимита.
- [ ] Смена настроек/пула не публикует результат отменённого обновления.

Добавить meaningful regression fixtures, вызывающие настоящий расчёт; запуск
изолированного C++ harness входит в 05.01 при отдельном разрешении.

## Фактический результат

Реализация не начата. Средний процент не вычисляется и не отображается.
