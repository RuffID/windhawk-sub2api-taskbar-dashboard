# 04.02. Версии, GitHub и отдельный кеш

Статус: not-started

[Этап](main.md) · [План](../main.md)

## Цель и результат

Версия установленного sub2api, независимая проверка опубликованных релизов
и правильные ссылки в существующем оформлении.

## Зависимости и границы

02.02 и подтверждённый контракт `system.read`. Источник — официальный
`Wei-Shaw/sub2api`, включая опубликованные prerelease. Адрес публичного
репозитория нового мода нужен до поставки
для второй GitHub-ссылки (Т3); не создавать репозиторий или релиз автоматически.

## Затрагиваемые части и работы

- [ ] Адаптировать чтение server version/check-updates по контракту sub2api;
  `data.version` — текущая версия, `data.has_update` из check-updates — источник
  индикатора обновления на taskbar, без ожидания полей codex-lb.
- [ ] Сохранить SemVer и учёт предварительных релизов, исходный tag для ссылки,
  отдельные состояния pending/unknown/error/rate limit/up-to-date/update available.
- [ ] Перенести часовой persistent cache и interprocess mutex под собственными
  именами; manual refresh/reload не обходят паузу, Reset/Retry-After учитываются.
- [ ] Не передавать GitHub ключ sub2api; сохранить ограниченную английскую
  диагностику HTTP/message/Remaining/Reset/Retry-After без секретов и тел целиком.
- [ ] Обновить ссылки релизов/тегов/репозитория мода и техническое описание.

## Проверки и критерии готовности

- [ ] Fixtures покрывают равную/старую/новую версию, beta.9/beta.10, stable,
  неизвестную текущую версию, не-JSON, 403/429 и отсутствие срока повтора.
- [ ] Повторное открытие кеша и два клиента соблюдают единый часовой минимум,
  не обращаясь к кешу исходного мода; отмена не оставляет вечную резервацию.
- [ ] Ошибка GitHub не скрывает аккаунты и не сообщает «Нет новых версий».
- [ ] Исходный tag экранируется в URL; области клика соответствуют своему назначению.

Фактическая проверка сервера/GitHub и пользовательского кеша разрешается отдельно;
изолированные тесты используют временный кеш и фиктивные ответы.

## Фактический результат

Реализация не начата. Версии и релизы не запрашивались.
