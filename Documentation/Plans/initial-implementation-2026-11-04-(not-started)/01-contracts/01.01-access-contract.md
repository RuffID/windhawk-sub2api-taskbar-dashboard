# 01.01. Контракт доступа к sub2api

Статус: completed

[Этап](main.md) · [План](../main.md)

## Цель и результат

Уточнить доступные поля и минимальные права администраторского API-ключа,
достаточные для карточек, недельного среднего, Reset и версии сервера.

## Зависимости и границы

Основание — статическое обследование [контрактов sub2api](../../../Technical%20documentation/integration.md).
Способ подключения определён:
администраторский ключ вводится прямо в настройках Windhawk. Работа с контрактами
и документацией; не создавать ключи, не читать секреты, не менять sub2api.

## Затрагиваемые части и работы

- [x] Сопоставить admin routes, middleware, каталог прав и scoped-проекции.
- [x] Составить таблицу: маршрут, envelope, поля, scope групп/типов, право,
  поведение 401/403/429 и частичных отказов.
- [x] Выбрать пассивное/активное чтение и документировать upstream-вызовы,
  обновление snapshots и возможное восстановление состояний на сервере.
- [x] Описать настройку `adminApiKey` с прямым вводом значения и пустым значением
  по умолчанию; передача в `x-api-key`, без переменных окружения и login/password.
- [x] Внести выбор в техническую документацию и будущие настройки 02.02.

## Проверки и критерии готовности

- [x] Каждый требуемый элемент UI имеет доступный источник либо явное открытое ограничение.
- [x] Полный административный доступ не требуется; выбран `full_access=false`.
- [x] Описаны безопасные английские диагностические события отказа авторизации
  и upstream-ошибки: только статус/код и безопасный ID, без ключа, cookie и тела ответа.
- [x] Права чтения не подразумевают reset, recover, смену настроек или restart.

Статический контракт не подтверждает права уже выданного ключа или версию
развёрнутого сервера. Реальную проверку не выполнять без разрешения.

## Фактический результат

04.11.2026 статически проверены `scopedAdminAccountDTO`, `scopedQuotaDTO`,
авторизация parent/shadow, envelope и различие restricted/full-access.
Выбраны список всех страниц OpenAI и прямой GET quota; минимум прав:
`accounts.read`, `accounts.identity.read`, `openai.quota.read`, `system.read`.
Общий usage и passive для OpenAI исключены из основного пути; точный reauth
не доступен выбранной проекцией и оставлен явным ограничением UI.
Внешние проверки не проводились, настройка и клиент не реализованы.
