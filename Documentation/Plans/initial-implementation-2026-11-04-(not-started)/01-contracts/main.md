# Этап 01. Доступ и правила данных

Статус: completed

## Цель и границы

Уточнить права чтения администраторского ключа и однозначный состав недельного
среднего до переноса интеграции. Ключ вводится в настройках Windhawk.
Серверные правки и запуск запросов сюда
не включены автоматически. [Общий план](../main.md).

Пользовательские правила состава, возраста, округления и официального GitHub
согласованы. Маршруты/права и ограничения проекций проверены по локальному коду.
Затрагиваются бизнес-требования, техническое обследование и контракты соседнего
sub2api только для чтения.

## Проверки и приёмка

- [x] Маршруты и заголовки подтверждены владеющим кодом; ключ модели не выдан за административный.
- [x] Поля карточек сопоставлены с проекцией; отсутствие точного reauth явно зафиксировано.
- [x] Для состава среднего, пропусков, устаревания, дублей и округления есть однозначные примеры.
- [x] Серверные побочные эффекты чтения/refresh описаны до выбора polling.

Оставшиеся [ограничения и внешние сведения](../open-questions.md) переданы этапам 04–05.
Живой доступ при необходимости подтверждается отдельно с разрешением.
