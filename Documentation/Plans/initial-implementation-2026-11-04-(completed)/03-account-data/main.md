## Проверки и приёмка

- [x] Список загружен со всех страниц, параллелизм GET quota ограничен, одна подписка учитывается один раз.
- [x] Использованный и оставшийся процент не перепутаны; тип окна установлен по контракту.
- [x] Ошибки отдельных GET quota не превращаются в полный успешный snapshot.
- [x] Известные, отсутствующие и устаревшие значения обрабатываются согласно 01.02.
- [x] Нормализованная модель позволяет сохранить внешний вид без чтения JSON из renderer.

Правила состава/расчёта описаны в 01.02 и актуальных бизнес-требованиях.
Отдельная диагностика переавторизации исключена из функциональности;
общие статусы и ошибки остаются. Данные берутся по выбранному прямому GET quota.
