## Фактический результат

04.11.2026 правила зафиксированы, технический маппинг проверен статически.
Все разрешённые группы; `status!=active`/ручное отключение исключаются, исчерпанный
недельный лимит остаётся 0%. Совпадающая полная upstream-пара account/user считается
один раз, без объединения по email; неизвестная идентичность даёт неполноту.
Свежесть — не более 900 секунд по `fetched_at`; пропуски исключаются с признаком
неполноты. Например, 80%/40% в двух группах дают 60%, отключение второй записи —
80%, её повтор как дубликата не меняет результат, отсутствие её лимита даёт 80%*.
Округляется только итог, половина вверх; 50,49/50,49/51,49 дают 51%.
Это документальные примеры, production-расчёт и тесты ещё отсутствуют.
