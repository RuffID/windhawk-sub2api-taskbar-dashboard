# 05.01. Статическая проверка, сборка и изолированные тесты

Статус: completed — 05.11.2026, в согласованном объёме.

[Этап](main.md) · [План](../main.md)

## Цель и результат

Доказательства компиляции и корректности парсинга/расчёта/ошибок без реального
сервера и включения мода в Explorer.

## Зависимости и границы

02–04 и [проверенные локальные пути toolchain](../../../Technical%20documentation/environment.md).
Перед каждым видом запуска установить точную
команду и файл и получить предусмотренное разрешение. Не запускать скрипт
под видом статической проверки. C++ harness не покрывается исключением для frontend-тестов.

## Затрагиваемые части и работы

- [x] Учтён статический обзор данных, ошибок, logs/secrets, includes и ownership
  этапов 02–04; отдельно проверена изоляция выполняемых fixtures.
- [x] Использованы существующие `tests/account_data.cpp`, `tests/popup_versions.cpp`
  и `tests/AGENTS.md`; fixtures вызывают production-код.
- [x] Оба файла скомпилированы Windhawk clang++ для x86-64 с флагами локальной
  editor database; артефакты находятся только в исключённом `artifacts/`.
- [x] Оба executable выполнены: exit 0, соответствующие сообщения об успехе.
- [x] Команды, предупреждение и границы подтверждения сохранены в
  [документе проверки](../../../Technical%20documentation/validation-2026-11-05.md).

## Проверки и критерии готовности

- [x] Production parser/loader/weekly/publication проверены на страницы/DTO,
  ошибки/частичность, null/неверные поля, окна, identity, дубли, свежесть,
  предел 899/900/901 и отмену.
- [x] Production version/cache/UI helpers проверены на SemVer, Reset, геометрию,
  ошибки доступа/лимитов, паузы, авторизацию, повреждённый кеш и отмену.
- [x] Assertions проверяют наблюдаемые результаты production-кода;
  замена расчёта константой или парсера пустым результатом нарушит эти ожидания.
  Фактический mutation-run не выполнялся.
- [x] Нет реального HTTP/listener, Windhawk/Explorer/UI, БД, пользовательского
  кеша или настроек. Временный кеш очищается RAII.
- [x] Сборка мода в Windhawk подтверждена пользователем отдельно от сборки tests.

## Фактический результат

Оба набора пройдены 05.11.2026. Один warning сравнения signed/unsigned
в `account_data.cpp:483`; ошибок сборки и failures нет.
Первая попытка запуска завершилась до main с 0xC0000135: загрузчик не находил
`libc++.whl`/`libunwind.whl`. После добавления x64 runtime Windhawk в PATH
процесса оба executable вернули 0. Код, глобальный PATH и установка не менялись.

Локальный HTTP-harness не запускался; реальный WinHTTP, timeout/разрыв соединения,
серверные побочные эффекты и журналы живого мода этими tests не подтверждены.
Полный/ограниченный DTO проверены синтетически; серверные права не эмулируются.
Непроверенная внешняя часть принята при закрытии согласно 05.02.
