# Требования к виджету

Статус: согласованные требования; реализована основа этапа 02, данные и версии ещё не подключены.
Основание: запрос пользователя от 04.11.2026 и его уточнения в текущем чате.

## Назначение

Виджет должен показывать состояние OpenAI-аккаунтов sub2api на панели задач
Windows 11. Нажатие открывает popup с карточками и подробностями лимитов.
Другие платформы в эту версию не входят.

Это отдельный проект рядом с `windhawk-codex-lb-taskbar-dashboard`.
Выполнен этап 02: перенесена независимая UI-основа и подготовлен транспорт.
Получение аккаунтов, расчёт среднего и привязка данных остаются этапам 03–04.
При отсутствии данных не выводится вымышленный процент.

## Средний недельный остаток

Для аккаунта с известным недельным расходом `u` процентов остаток равен `100 − u`.
Сводное значение — среднее арифметическое остатков включённых аккаунтов:

`средний остаток = (r₁ + r₂ + … + rₙ) / n`.

Пример с условными данными: израсходовано 20% и 60%, осталось 80% и 40%;
виджет показывает среднее 60%. Тарифы не задают веса в этой формуле.
Показатель не означает общий запас запросов или долларов.

Учитываются все OpenAI-аккаунты, доступные ключу, независимо от группы.
Отключённые и неработающие аккаунты исключаются из среднего, но остаются
в карточках со своим статусом. Исчерпанный недельный лимит сам по себе не
исключает аккаунт: достоверный остаток 0% участвует в расчёте.
Если несколько записей относятся к одной подписке, её недельный остаток
учитывается один раз. Карточки записей при этом не скрываются.

При отсутствии данных части подписок среднее считается только по известным
пригодным значениям с признаком неполноты: например, `80%*`; в popup указывается,
по скольким подпискам из выбранного пула рассчитан процент. Неизвестное значение
не считается ни 0%, ни 100%. Месячный лимит не подставляется вместо недельного.

Данные пригодны для среднего не дольше 15 минут с момента их получения от
источника. Повторное чтение старого снимка не обновляет его возраст. После
ошибки обновления прошлое значение сохраняется с отметкой устаревания и временем
получения до истечения этих 15 минут, затем исключается из текущего среднего.
Если пригодных недельных значений не осталось, процент заменяется сообщением
о недоступности; старые значения в карточках могут оставаться только с явной
отметкой возраста и без участия в среднем.

Среднее вычисляется по исходным дробным остаткам. Только итог округляется до
ближайшего целого, половина вверх: `50,5% → 51%`. Цвет панели определяется
показанным целым процентом. Пример: остатки 50,49%, 50,49% и 51,49% дают 51%.

## Внешний вид и взаимодействия

Сохранить оформление и поведение эталонного мода версии 1.3:

- Компактный процент рядом с системным треем; работа на основном и дополнительных
  мониторах, восстановление виджета при перестроении панели задач.
- Цвета остатка: от 61% зелёный, от 31% до 60% жёлтый, ниже 31% красный.
- Тёмный полупрозрачный popup, скругления, обводки, непрозрачный текст,
  масштабирование под DPI; две карточки в строке, минимум четыре без прокрутки
  при условиях эталона, прокрутка для остальных.
- Имя и email аккаунта, доступные окна лимитов, время до сброса, сортировка
  по оставшемуся длинному лимиту по возрастанию; неизвестные значения после известных.
- Сохранить поддержку отображения месячного окна в карточке, если оно предоставлено
  для OpenAI; это не меняет формулу недельного среднего.
- Отсутствующее 5-часовое окно скрывается, длинное занимает ширину карточки.
  Отсутствующие данные отображаются без выдуманных значений.
- Отображение `Reset (N)` с ближайшим сроком истечения;
  неизвестное/нулевое количество скрывает badge, неизвестный
  срок скрывает только отсчёт. Срок до семи дней включительно — красный.
- Заголовок с остатком, адресом сервера, версией мода; версия сервера и состояние
  обновления с прежними рамками, текстом и областями клика.
- Кнопка обновления с состояниями наведения/нажатия, время последнего успешного
  обновления, закрытие popup по нажатию вне него.
- Ссылки на релизы сервера и отдельный репозиторий нового мода, когда его адрес
  будет известен. Не оставлять ссылки нового мода ведущими в исходный проект.

Оформление сохраняется; источники данных и названия адаптируются под sub2api.
Отдельный значок и сообщение «Нужна переавторизация» в этот мод не включаются.
Определять такой диагноз по общей ошибке запроса не требуется; известные
статусы аккаунта и общие ошибки доступа/сети остаются видимыми.
Само отображение Reset не означает выполнение сброса: расходовать попытки
сброса, менять аккаунты или обновлять сервер из виджета не требуется.

## Подключение и ошибки

Использовать администраторский API-ключ sub2api. Ключ должен задаваться прямо
в поле «Администраторский API-ключ» настроек модификации Windhawk, без настройки
переменных окружения, логина или пароля. Начальное значение поля — пустая строка.
Пустой ключ означает, что подключение ещё не настроено; запросы с ним не отправляются.
После сохранения нового ключа следующее обновление должно использовать новые
настройки, не публикуя результаты отменённого запроса со старым ключом.

Допускаются полный и ограниченный администраторские ключи. Чтение квоты полным
ключом может инициировать серверную проверку уже включённого автосброса и при
выполнении его условий привести к расходу Reset; такое поведение допустимо.
Мод не включает и не перенастраивает автосброс, не вызывает отдельные операции
сброса или изменения аккаунтов. Ограниченный ключ остаётся допустимым вариантом;
необходимые права чтения описаны в технической документации.
Значение ключа не показывается в popup, не попадает в сообщения ошибок и логи.

При ошибке доступа не показывать успешное обновление данных. Ошибка проверки
версий не должна превращаться в сообщение «Нет новых версий» или скрывать
успешно полученные аккаунты. Проверка релизов должна сохранить часовой минимум
между запросами и учёт ограничений GitHub, как у эталона.

Релизы сервера сравниваются с официальным репозиторием `Wei-Shaw/sub2api`,
включая опубликованные предварительные версии. Кнопка релизов открывает этот
проект, ссылка новой версии — страницу конкретного исходного тега.
