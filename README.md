# Sub2API Taskbar Dashboard

**Недельные лимиты OpenAI — прямо на панели задач Windows 11.**

Мод для [Windhawk](https://windhawk.net/), созданный в первую очередь для
[sub2api](https://github.com/Wei-Shaw/sub2api). Показывает средний остаток
недельного лимита OpenAI-аккаунтов рядом с системным треем. Нажатие на виджет
открывает окно с карточками аккаунтов, квотами и сроками сброса.

## Возможности

- **Общий остаток на панели задач** с цветовой индикацией: зелёный от 61%,
  жёлтый от 31% до 60%, красный ниже 31%.
- **Карточки аккаунтов** с именем, email и доступными окнами лимитов:
  5 часов, неделя или месяц.
- **Сроки сброса и Reset** — обратный отсчёт, количество доступных сбросов
  и ближайшее истечение их срока.
- **Качество данных** — отметки ошибок, устаревания и неполного результата.
- **Версия sub2api и новые релизы** со ссылками на GitHub.
- **Автоматическое и ручное обновление данных**; интервал задаётся в настройках.

Процент — среднее арифметическое недельных остатков, а не сумма квот или денежный
баланс. Например, остатки **80%** и **40%** дают **60%**. Повторные записи одной
подписки учитываются один раз; месячный лимит не заменяет недельный.

Если часть данных недоступна, рядом с процентом появляется `*`, а в окне
указывается полнота расчёта. Данные старше 15 минут исключаются из среднего.
При отсутствии пригодных значений виджет сообщает о недоступности данных.

## Установка

Нужны **Windows 11 x64**, установленный [Windhawk](https://windhawk.net/)
и доступ к администраторскому API sub2api.

1. Скачайте [исходники мода](https://github.com/RuffID/windhawk-sub2api-taskbar-dashboard)
   через **Code → Download ZIP** и распакуйте в постоянную папку.
   Сохраните `mod.wh.cpp` и всю папку `src/` вместе.
2. Откройте `mod.wh.cpp` и в строке `@compilerOptions` замените путь после
   `-I` на абсолютный путь к распакованной папке. Например:

   ```text
   -I"C:/WindhawkMods/sub2api-taskbar-dashboard"
   ```

   Сохраните остальные параметры этой строки.
3. В Windhawk создайте новый мод и замените исходный текст содержимым
   подготовленного `mod.wh.cpp`. Сохраните и скомпилируйте мод.
4. Откройте настройки мода, укажите адрес sub2api и администраторский API-ключ
   по разделу ниже, затем включите мод.

> **Важно:** одного `mod.wh.cpp` недостаточно. Папка `src/` должна оставаться
> доступной по include-пути при каждой компиляции.

## Подключение

| Настройка | Что указать |
| --- | --- |
| **Адрес sub2api** | Базовый HTTP(S) адрес, например `https://sub2api.example.com`. Допускается префикс reverse proxy; добавлять `/api/v1/admin` не нужно. |
| **Администраторский API-ключ** | Полный ключ sub2api без `Bearer` и кавычек. Поддержка ограниченного ключа зависит от прав и версии сервера — [подробнее](Documentation/Technical%20documentation/integration.md). |
| **GitHub-токен** | Необязательный Personal Access Token для чтения публичных релизов. Можно оставить пустым. |
| **Интервал обновления, секунды** | По умолчанию 60 секунд; минимальный интервал — 30 секунд. |

Замените начальные примеры адреса и ключа своими значениями: с примерами и пустыми
полями запросы не отправляются. Логин, пароль и переменные окружения не требуются.
Ключи задаются в настройках Windhawk; добавлять их в исходники не нужно.

> **Полный ключ и автосброс:** чтение квоты может запустить серверную проверку
> уже включённого автосброса и привести к расходу Reset. Мод сам не настраивает
> автосброс и не вызывает отдельную операцию сброса.

Администраторский ключ отправляется только в sub2api, GitHub-токен — только
в GitHub. Проверка релизов выполняется отдельно от загрузки аккаунтов, не чаще
раза в час и с учётом ограничений GitHub. Ошибка проверки версий не скрывает квоты.

## Обновление мода

1. Скачайте новую версию исходников из
   [репозитория мода](https://github.com/RuffID/windhawk-sub2api-taskbar-dashboard).
2. Замените `mod.wh.cpp` и папку `src/` комплектом из одной версии.
3. Восстановите свой абсолютный include-путь в `@compilerOptions`.
4. Откройте существующий мод в Windhawk, замените его исходный текст обновлённым
   `mod.wh.cpp`, сохраните и повторно скомпилируйте.

**Кнопка обновления в окне перечитывает данные.** Проверка новых релизов sub2api
показывает доступную версию и ссылку; обновления мода и сервера устанавливаются
отдельно.
