# Popup

window.h владеет окном Sub2ApiDashboardPopup, мышиным hook и обработкой сообщений.
g_popupCreationMutex сериализует создание; взаимодействия выполняются на
потоке окна. Запрещено создавать окно после g_unloading.
Снимать hook, уничтожать окно и unregister class при shutdown, включая failure.
Области клика должны соответствовать реально нарисованным ссылкам.
Геометрия окна/карточек сохранена; внутренняя граница заголовка отведена под
измеренный счётчик и процент со *. Текст версии/статуса может сокращаться
многоточием; кликабелен только видимый tag, всегда URL-encoded.
Пустой успешный пул отличается от ожидания/ошибки. Неизвестный URL мода
не создаёт hit-test область. Кнопки/наружный mouse hook/DPI остаются прежними.

Renderer не читает сеть: данные копируются под g_dashboardMutex. Настройки
используются только для безопасного адреса/состояния подключения, ключ не рисуется.
Карточки и сводка приходят одним опубликованным snapshot. В заголовке — счётчик
подписок и * для неполного среднего; ? означает неопределённый знаменатель.
Карточка показывает общий статус/ошибку и возраст отдельно от длинного reset.
Версии публикуются отдельно от account snapshot; ошибка не скрывает аккаунты.
