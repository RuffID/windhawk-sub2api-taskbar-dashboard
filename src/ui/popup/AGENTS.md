# Popup

window.h владеет окном Sub2ApiDashboardPopup, мышиным hook и обработкой сообщений.
g_popupCreationMutex сериализует создание; взаимодействия выполняются на
потоке окна. Запрещено создавать окно после g_unloading.
Снимать hook, уничтожать окно и unregister class при shutdown, включая failure.
Области клика должны соответствовать реально нарисованным ссылкам.

Renderer не читает сеть: данные копируются под g_dashboardMutex. Настройки
используются только для безопасного адреса/состояния подключения, ключ не рисуется.
В текущей основе версии и карточки не загружаются; показывать недоступность.
