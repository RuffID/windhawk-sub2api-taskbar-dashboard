# Интерфейс

taskbar/widgets.h — XAML-виджет; popup/window.h — окно и взаимодействия;
rendering/popup.h — GDI/DPI/прозрачность и renderer.
Сохранять оформление и размеры исходной основы. Не соединять UI с HTTP:
ручное обновление только через core/refresh_api.h.

Показывать отсутствие данных явно. Не рисовать вымышленные проценты,
карточки или диагноз переавторизации. Текст ошибок не должен содержать ключ,
серверный response body или credentials. Публичный URL нового мода пока
неизвестен: его значок отключён, не подставлять старый репозиторий.
Карточки и сводка приходят одним опубликованным snapshot. В заголовке — счётчик
подписок и * для неполного среднего; ? означает неопределённый знаменатель.
Статус/ошибка и возраст имеют отдельную нижнюю строку карточки и не скрывают
срок сброса. Версии используют versions/presentation.h и не скрывают карточки.
