# Отрисовка

popup.h сохраняет layered dark popup, opaque glyphs, rounded surfaces,
две карточки в строке, scrollbar и DPI. GDI-ресурсы освобождать тем же владельцем;
не упрощать прозрачность до общей alpha текста.

Renderer принимает только UI-модели из core/state.h, без Settings/ключей/ответов.
Отдельный badge переавторизации исключён. Неизвестные проценты — n/a;
Reset показывается только при известном положительном количестве.
dataQualityText — готовая безопасная UI-строка общего статуса/ошибки/возраста,
на этапе 03 занимает строку длинного reset. Renderer не вычисляет среднее.
Версии пока недоступны; Pending не выдаётся за отсутствие обновлений.
